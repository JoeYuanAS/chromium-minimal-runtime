# 有头 / 无头一致性设计

## 1. 问题

很多现成工具的有头模式和无头模式行为不同，例如：

- `navigator.webdriver`
- Canvas 输出不同
- WebGL renderer 不同
- 请求头不同
- TLS/HTTP2 指纹不同
- 页面可见性状态不同
- GPU/Compositor 路径不同

采集浏览器需要尽可能让二者一致。

## 2. 设计原则

不要把无头模式当成另一个浏览器。

```text
BrowserRuntime
  ├── HeadfulView: 显示页面
  └── HeadlessView: 不显示页面
```

两者共享：

- BrowserContext
- StoragePartition
- NetworkContext
- FingerprintProfile
- WebContents
- RenderProcess 配置
- Blink 初始化参数

## 3. 实现方式

### 有头模式

创建窗口，显示渲染输出。

### 无头模式

不创建用户可见窗口，但仍保留真实渲染路径。截图、Canvas、WebGL 仍然走相同渲染流程。

## 4. 检查清单

每个 Profile 需要比较：

- document.visibilityState
- navigator.webdriver
- navigator.plugins.length
- navigator.languages
- permissions.query
- canvas hash
- webgl vendor/renderer
- audio hash
- screen 信息
- timezone
- HTTP 请求头
- TLS JA3/JA4
- HTTP2 SETTINGS

## 5. 测试工具建议

建立内部指纹测试页面，输出所有检测点，然后分别用有头/无头跑一次，对比结果。
